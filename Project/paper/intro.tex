\section{Introduction}
This document outlines the numerical methods, results, and interpretation of the final project for the Quantitative Economics course.
We will discuss:

\vspace{\baselineskip}

\noindent\textbf{Numerical Methods}
\begin{itemize}
    \item Grid construction for Captial ($k$) and Productivity ($z$)
    \item Interpolation methods used for value function approximation
    \item VFI process with golden-section and Howard policy iteration
    \item MoM Estimation setup for $\{\gamma_{adj}, F, p_s\}$.
\end{itemize}

\vspace{\baselineskip}

\noindent\textbf{Interpretation of Results}
\begin{description}
    \item[Stage(s) 1, 2, 3:] Fixed cost and irreversibility implications over fixed $\gamma_{adj}$.
    \item[SMM:] Parameter estimation output
    \item[Policy Functions:] $V$ and $i^*$ over $z$ levels.
    \item[Stationary Distribution:] $\mu$ density, moments, and interpretation.  
\end{description}
